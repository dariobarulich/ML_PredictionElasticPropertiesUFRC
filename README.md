# Machine Learning-Based Elastic Property Prediction for High-Fiber-Content Unidirectional Composites

[![Python 3.8+](https://img.shields.io/badge/python-3.8+-blue.svg)](https://www.python.org/)
[![PyTorch](https://img.shields.io/badge/PyTorch-1.10+-ee4c2c.svg)](https://pytorch.org/)

Este repositorio contiene la implementación del modelo sustituto para la predicción de las **8 propiedades elásticas efectivas** de UFRC.

## 📄 Publicación
* **Título:** Machine Learning-Based Elastic Property Prediction for High-Fiber-Content Unidirectional Composites
* **Autores:** Néstor Darío Barulich, Fernando Diego Carazo, Patricia Mónica Dardati
* **Revista:** Mechanics of Advanced Composite Structures (MACS)
